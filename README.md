# Zlux POS
 
Zlux POS is a modern point-of-sale application built with Flutter, designed for merchants who need a simple yet powerful way to manage their business. It allows merchants to add and manage products, process transactions with automatic calculations, and print receipts directly to Bluetooth thermal printers.
 
## Features
 
- 🛒 **Product & Transaction Management** — Add products and process sales transactions with real-time calculation
- 🖨️ **Bluetooth Thermal Printer Support** — Print receipts directly from the app
- 📜 **Transaction History** — View a complete log of past transactions
- 💰 **Income & Expense Tracking** — Record additional income (e.g. tenant rental fees) and additional expenses beyond regular sales
- 📊 **Daily Reports** — View daily reports with income, expense, and profit breakdowns, with the option to export to PDF
- 🌐 **Multi-language Support** — Available in English and Indonesian
- 🌗 **Dark & Light Theme** — Switch between dark and light mode for a comfortable viewing experience
## Tech Stack
 
- **Framework:** Flutter
- **Architecture:** Clean Architecture / MVVM
## Getting Started
 
### Prerequisites
 
- Flutter SDK installed
- A physical or virtual device with Bluetooth support (for printer testing)
### Installation
 
```bash
git clone https://github.com/<your-username>/zlux-pos.git
cd zlux-pos
flutter pub get
flutter run
```
