<div align="center">

# 🧾 Zlux POS

**A modern point-of-sale app built with Flutter**

Manage products, process transactions, and print receipts — all in one lightweight app.

</div>

---

## ✨ Features

| | |
|---|---|
| 🛒 **Product & Transaction Management** | Add products and process sales transactions with real-time calculation |
| 🖨️ **Bluetooth Thermal Printer Support** | Print receipts directly from the app |
| 📜 **Transaction History** | View a complete log of past transactions |
| 💰 **Income & Expense Tracking** | Record additional income (e.g. tenant rental fees) and expenses beyond regular sales |
| 📊 **Daily Reports** | View income, expense, and profit breakdowns — exportable to PDF |
| 🌐 **Multi-language** | Available in English and Indonesian |
| 🌗 **Dark & Light Theme** | Switch between themes for a comfortable viewing experience |

## 🚀 Getting Started

### Prerequisites

- Flutter SDK installed
- A physical or virtual device with Bluetooth support (for printer testing)

### Installation

\`\`\`bash
git clone https://github.com/<your-username>/zlux-pos.git
cd zlux-pos
flutter pub get
flutter run
\`\`\`
